# 🚀 One-Click Deployment Guide

## **Fastest Deployment (Render) - 3 Steps**

### **Step 1: Install Production Dependencies**

```powershell
pip install gunicorn whitenoise python-decouple psycopg2-binary
pip freeze > requirements.txt
```

### **Step 2: Push to GitHub**

```powershell
git add .
git commit -m "Add one-click deployment configuration"
git push origin main
```

### **Step 3: Deploy on Render (One Click!)**

1. **Go to:** https://dashboard.render.com/
2. **Click:** "New+" → "Web Service"
3. **Select:** Your GitHub repo (NoNameMan07/CAREER-COMPASS)
4. **Configure:**
   - **Name:** career-compass (or your preferred name)
   - **Branch:** main
   - **Build Command:** `pip install -r requirements.txt && python manage.py migrate && python manage.py collectstatic --noinput`
   - **Start Command:** `gunicorn myproject.wsgi:application`
5. **Environment Variables** (auto-populated, but check):
   - `SECRET_KEY`: (auto-generated, keep it)
   - `DEBUG`: `False`
   - `ALLOWED_HOSTS`: `your-app.onrender.com`
   - `USE_LOCAL_MODEL`: `True`
6. **Database:** Render auto-creates PostgreSQL
7. **Click:** "Create Web Service"

**✅ DONE! Your app is live in ~5 minutes**

## **Troubleshooting**

### **"Static files not loading"**
```powershell
# SSH into Render instance and run:
python manage.py collectstatic --noinput
```

### **"Database connection failed"**
- Check DATABASE_URL in Render env variables
- Verify migrations ran: `python manage.py migrate`

### **"ML model not found"**
- Ensure `models/role_matcher.joblib` is in repo
- Check `USE_LOCAL_MODEL=True` in env

### **"Secret key error"**
- Render auto-generates, but verify in dashboard
- Must be set before deployment

DEBUG               → False (production)
ALLOWED_HOSTS       → your-app.onrender.com
USE_LOCAL_MODEL     → True (uses joblib model, no LLM needed)
DATABASE_URL        → Auto-set by Render
OLLAMA_URL          → Optional, defaults to localhost
OLLAMA_MODEL        → Optional, defaults to mistral
